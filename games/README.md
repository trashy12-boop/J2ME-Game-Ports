# J2ME Games

This folder holds the playable Java ME builds for the projects listed in the [main README](../README.md).

| Game | Version | Archive |
| --- | --- | --- |
| Nyan Cat: Lost in Space | 0.6.0 | [Download JAR](Nyan_Cat_Lost_in_Space_J2ME_320x240_v0.6.jar) |
| Suika Game | 0.2.5 | [Download JAR](Suika_Game_0.2.5.jar) |

The v0.6 Nyan Cat build fixes the rainbow seam and reduces temporary string allocations in score formatting. It requires **MIDP 2.0 / CLDC 1.1** and is designed for 320×240 resolution.

To run a game, download the JAR file and load it into a compatible J2ME emulator or supported Java ME phone.

These are unofficial experimental ports. Compatibility and performance vary by device and emulator.
