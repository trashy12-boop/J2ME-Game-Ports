# J2ME Game Ports

A collection of unofficial game ports, conversions, and experiments made for **Java ME (J2ME)**. The idea is simple: take games that weren't originally designed for old Java phones and see how far they can go on MIDP devices and emulators.

Created and maintained by **Trashy12**.

## Games

| Game | Version | Platform | Notes |
| --- | --- | --- | --- |
| **[Nyan Cat: Lost in Space](games/Nyan_Cat_Lost_in_Space_J2ME_320x240_v0.6.jar)** | **v0.6.0** | Java ME (CLDC 1.1 / MIDP 2.0) | Fan port for **320×240** displays; fixes the rainbow seam and reduces score-formatting allocations. |
| **[Suika Game](games/Suika_Game_0.2.5.jar)** | **v0.2.5** | Java ME (CLDC 1.1 / MIDP 2.0) | Personal Java ME conversion. |

> Both downloadable JARs are available in the [`games/`](games/) folder.

## How to play

1. Download the game's `.jar` file from the `games/` folder
2. Open it in a compatible J2ME emulator or on a device that supports **MIDP 2.0 / CLDC 1.1**.
3. For the Nyan Cat port, use a **320×240** display setting when your emulator allows it.

Compatibility and performance can vary across devices and emulators. These are experimental projects, not guaranteed to run everywhere.

## About this repository

This is a home for my J2ME projects: ports, conversions, experiments, and updates. Some games may be unfinished, have missing features, or work better in certain emulators. More titles and improved versions may be added over time.
